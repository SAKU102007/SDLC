# Лабораторная работа №1 — вариант 20

## Тема
**«Возраст в неожиданных единицах»**.

Язык: **C#**  
GUI: **Windows Forms**  
Архитектура: **MVC с активной моделью**  
Целевая платформа: **.NET 8.0 for Windows**

## Что делает программа

Пользователь вручную вводит дату рождения в формате `ДД.ММ.ГГГГ`. Стандартный `DateTimePicker` не используется.

Программа выводит:

- полный возраст в годах;
- общий возраст в месяцах;
- общий возраст в днях;
- общий возраст в минутах;
- примерное количество выпитых чашек кофе;
- количество сериалов длительностью 45 минут;
- примерную длину прокрученной ленты социальных сетей в километрах.

Последняя введённая дата автоматически сохраняется в `%APPDATA%/AgeUnexpectedUnits_MVC/settings.json` и восстанавливается при следующем запуске.

## Принятые учебные коэффициенты

Эти величины нужны только для демонстрации требований варианта и явно заданы в модели:

- 3 чашки кофе в сутки;
- 1 серия = 45 минут;
- 1 км ленты соцсетей = 30 минут прокрутки.

## MVC с активной моделью

```text
MainForm (View)
      │ пользователь нажимает «Ввести данные»
      ▼
AgeController (Controller)
      │ передаёт данные
      ▼
AgeModel (Active Model)
      │ изменяет состояние + выполняет расчёты
      │
      └──── StateChanged ────► Controller ────► View
```

### Почему модель активная

`AgeModel` хранит состояние предметной области, содержит бизнес-логику расчёта, сохраняет данные и публикует событие `StateChanged` после изменения состояния. View не выполняет вычисления и не изменяет Model напрямую.

## Запуск

Откройте `AgeUnexpectedUnits_MVC.csproj` в Visual Studio 2022 с установленным workload **Desktop development with .NET**.

Либо в терминале Windows:

```powershell
dotnet restore
dotnet run
```

## Проверка ошибок

Проверяются:

- пустой/неверный формат даты;
- несуществующие даты, например `31.02.2000`;
- будущая дата;
- год меньше 1900.

## Отладка

Для демонстрации отладчика удобно поставить breakpoint в:

```text
Controllers/AgeController.cs   → TryApplyDialog()
Models/AgeModel.cs             → Calculate()
Models/AgeModel.cs             → SetBirthDate()
```

Затем ввести дату и пошагово показать переход `View → Controller → Model` и возврат события `StateChanged`.
